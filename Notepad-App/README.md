# NotePad
 
A lightweight multi-tab text editor built with JavaFX, supporting basic file operations and permissions.
 
## Features
 
- Multi-tab editing — open and edit multiple files simultaneously
- Create new files with custom names via an in-app dialog
- Open existing files from disk
- Save and Save As with `.txt` extension filter
- Cut, Copy, Paste, Delete via Edit menu (with keyboard shortcuts)
- Unsaved changes indicator — tab title prefixed with `*` when modified
- Set a file as Read Only (toggleable) at the OS level
## Keyboard Shortcuts
 
| Action | Shortcut |
|--------|----------|
| New    | Ctrl+N   |
| Save   | Ctrl+S   |
| Cut    | Ctrl+X   |
| Copy   | Ctrl+C   |
| Paste  | Ctrl+V   |
| Delete | Ctrl+D   |
